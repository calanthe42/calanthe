CALANTHE — ARABIC REVIEW SHEET

How to use this: read the Arabic against the English. Where it is wrong,
write the correct Arabic on the CORRECTION line. Leave it blank if the
Arabic is right. Nothing else needs filling in.

A {word} in braces is replaced at runtime by a real value — a price, a
name, a number. Keep it exactly as written, but move it to wherever it
belongs in the Arabic sentence.
