Date: 2026-08-28 · Commit: `feat(backend): B0 foundation`

## What was built

1. **Environment fix** — project moved from the OneDrive-synced folder to
   `C:\dev\calanthe` (OneDrive was corrupting `.next` tmp files and
   killing the dev server). Git history verified intact, node_modules
   reinstalled. The OneDrive copy is now dead — work only in `C:\dev`.
2. **Payload CMS 3.88 installed into the existing Next.js app.**
   - App restructured for two root layouts: storefront moved to
     `src/app/(frontend)/…` (its root layout carries fonts/Lenis/
     observer); Payload owns `src/app/(payload)/…` (`/admin`, REST
     `/api/[...slug]`, GraphQL `/api/graphql`).
   - `src/payload.config.ts` + `src/collections/Users.ts` (roles
     admin/staff/customer, deny-by-default access, role changes
     admin-only, login attempt lockout).
   - Postgres adapter (Drizzle) with **push disabled everywhere** —
     migrations only, `src/migrations/` (`pnpm migrate:create` /
     `pnpm migrate`).
   - `withPayload` wraps next.config; `@payload-config` tsconfig alias.
3. **Env schema (Zod), fail-fast** — `src/lib/env.ts`; validated at boot
   via `src/instrumentation.ts`. Production runtime additionally
   requires Sentry + Upstash vars (build phase exempt — the build makes
   no network calls; boot still refuses).
4. **Sentry** — env-gated init in instrumentation (server) with
   `onRequestError` capture; no DSN → cleanly disabled in dev.
5. **Upstash Redis** — `src/lib/redis.ts`: null-safe client + sliding-
   window `rateLimit()` factory for B3–B5 endpoints.
6. **Money foundation** — `src/lib/money.ts` (integer fils, assertions,
   AED formatting, safe add, percent w/ half-up rounding) + 5 Vitest
   tests (`pnpm test`).
7. **Docs system** — this file, README rewrite, RUNBOOK, SECURITY
   checklist, CHANGELOG.

## Decisions

- **Webpack production builds** (`next build`, no `--turbopack`): Payload
  blocks Turbopack builds on Next 15; upgrading to Next 16 mid-build was
  rejected as risk. Dev still uses Turbopack.
- **push:false even in dev** — every environment runs the same reviewed
  migration files.
- **Customers get role `customer` now** even though OTP auth lands in
  B5 — access rules are written against the final shape from day one.
- Root `not-found` moved into `(frontend)`; unmatched non-group paths
  fall back to Next's default 404 (known small gap, revisit later).
