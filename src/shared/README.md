# `src/shared/` — safe on both sides

Types, Zod schemas, constants and pure utilities that run unchanged in
the browser and on the server.

Import with `@shared/*`.

## The admission test

> **Would shipping this file to the browser be harmless, and does it
> work on the server unchanged?**

If either answer is no, it does not belong here.

## May import

`zod`, `clsx`, `tailwind-merge`. Nothing else.

## May NOT import

- `@frontend/*`, `@backend/*`, `@admin/*`
- `payload`, any SDK, any database client
- `process.env`, any secret
- React

`shared` depends on **nothing** in this repository. It is the sink of
the dependency graph, which is what makes cycles impossible.

## Planned layout

```
types/
  payload-generated.ts   generated by `pnpm generate:types`
  index.ts
schemas/                 Zod
constants/               cutoff hour, min budget, free-delivery threshold
utils/                   money.ts, cn.ts, format.ts
```

## Why `schemas/` matters most

One Zod schema validates the checkout form **in the browser** and the
request body **on the server**. They cannot drift, because they are one
file. Duplicating validation is how a client and server quietly start
disagreeing about what is valid.

## Why generated Payload types are allowed here

They are pure type declarations — erased at build, zero runtime, unable
to carry a secret. A generated file is safe in `shared/`; a generated
*client* would not be.
